# Changelog

## 0.9.0 — 2026-11-18 (playable pre-release)
- Created the complete five-chapter narrative campaign for THE MAZE: SIGNAL LOST.
- Rebuilt gameplay in testable ES modules while preserving the user's original Chapter 1 standalone prototype as a legacy file.
- Added procedural 2.5D renderer, interactive survivors/creatures, four firearms, survival/stealth, pickup and chapter systems.
- Added a multi-screen menu, settings persistence, challenges, difficulties, chapter progression, journal, achievements and three endings.
- Added five new original chapter soundtrack loops, reactive procedural sound effects and original SVG key art/favicon.
- Introduced studio design, story, technical, QA and production documentation plus CI and Node unit tests.
- Known limits: no complete manual browser playthrough, no production-quality hand-authored 3D scenes or finished dialogue/animation pass.
